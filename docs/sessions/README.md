# Session notes

Each working session keeps one short file here, named after itself (`interface.md`, `rules.md`, `computer-opponent.md`, `figures.md`, `project-management.md`). The file is the session's memory: a conversation can be cut short or lost, the file stays, and the project-management session reads it instead of guessing from the commits.

**Overwrite it, never append; at most 25 lines.** Update it when you finish something, when you stop, and when you are waiting for the owner.

```markdown
# <session> · <date and time>
Doing: <the one task in hand>
Next: <the step after it>
Waiting for the owner: <the one question, in his words; or "nothing">
Last checked: <what was run and its result, e.g. "npm run verify: all passed, 14 Nov 10:20">
Files in hand: <files with unpushed or half-done work, or "none">
Notes: <anything the next session must know and cannot see in the code>
```
