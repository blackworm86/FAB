# Italian glossary for FAB (4.6)

Use these terms everywhere (interface and tutorials) so the game reads as one voice. Register: plain, direct Italian, second person singular ("tocca", "scegli"), short like the English. Rule numbers, unit names, place names, scenario names and dice values stay as they are. The rulebooks themselves stay in English.
